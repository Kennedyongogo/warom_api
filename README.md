# WAROM API

Express + Sequelize backend for the users app, chatters app, admin, and public site (policies/inquiry).

See [WAROM_API.md](./WAROM_API.md) for the route map.

```bash
npm install
npm start
```

Requires `.env` with Postgres (`PGHOST`, `PGPORT`, `PGDATABASE`, `PGUSER`, `PGPASSWORD`) and `JWT_SECRET`.
